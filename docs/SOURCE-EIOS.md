## 2. Очное расписание (`Очная форма.xlsx`)

### Структура

4 листа по курсам: `1 курс ` (с пробелом!), `2 курс`, `3 курс`, `4 курс`.

Каждый лист — сетка:

```
R1: шапка «ФГБОУ ВО "Заполярный государственный университет..."»
R2: «РАСПИСАНИЕ УЧЕБНЫХ ЗАНЯТИЙ ОЧНОГО ОТДЕЛЕНИЯ НА ПЕРВЫЙ СЕМЕСТР 2026-2027»
R3: A=«Группа», C..P = названия групп      ← заголовок колонок
R4: «с 9.00 до 9.20 — "Разговоры о важном"» (только 1 курс)
R5:  A=«ПОНЕДЕЛЬНИК», B=«1 пара»           ← начало дня
R6:  (пустая строка)
R7:  B=«2 пара»
...
R13: B=«5 пара»
R15: A=«ВТОРНИК», B=«1 пара»
```

**Ключевые правила:**

- **День недели** — в колонке `A`, встречается только на первой паре дня.
  Дальше колонка `A` пустая — день надо «держать» в памяти.
- **Номер пары** — в колонке `B`, текст вида `«1 пара»`.
- **Группы** — в строке 3, начиная с колонки `C`. Колонка → группа.
- **Шаг 2 строки** на пару: пара занимает **две строки** (`R` и `R+1`).
- **5 пар в день**, 6 дней (Пн–Сб). Воскресенья нет.

### 🔑 Формат ячейки: две строки = две недели

**Это главное открытие.** Пара занимает две строки, и они имеют разный смысл
в зависимости от того, **объединены ли они** (`merge`).

#### Случай A — ячейка объединена (`R:R+1`), 928 штук

Одна пара на **обе** недели. Внутри — предмет + перевод строки + преподаватель:

```
Физика
Ивасишина Е.Е.
```

#### Случай B — ячейка НЕ объединена, 38+15 штук

**Верхняя и нижняя строки — это ДВЕ РАЗНЫЕ ПАРЫ: на чётную и нечётную неделю.**

Пример (ДП-26, среда, 1 пара):

```
верх (P25): «Информационно-коммуникационные технологии в делопроизводстве / Харькова Д.А.»
низ  (P26): «Организация документооборота и документирование управленческой деятельности / Харькова Д.А.»
```

Это **не** одна пара с длинным названием — это два разных предмета,
которые идут через неделю.

#### 🎯 Какая строка какой неделе соответствует — УСТАНОВЛЕНО

| Строка | Неделя |
|---|---|
| **верхняя (TOP)** | **чётная** |
| **нижняя (BOT)** | **нечётная** |

**Доказательство** (перекрёстная сверка с листком замен):

1. `СМф-24`, понедельник, 5 пара: TOP пуст, BOT = «Строительство дорог…».
   Замена на **26.10.2026 (понедельник, нечётная)** говорит:
   «было: Строительство дорог – Борисенко А.Д.» → **совпало с BOT**.
2. `СМк-25`, понедельник, 5 пара: TOP = «Тракторы и автомобили»,
   BOT = «История России». Замена на **26.10 (нечётная)**: «было: История»
   → **снова BOT**.

Оба случая — нечётная неделя. Ни одного противоречия не найдено.

#### Пограничные случаи

- **Заполнена только одна строка** — значит на второй неделе пары нет.
  - 8 ячеек «только низ» → пара **только на нечётной**.
  - 7 ячеек «только верх» → пара **только на чётной**.
- **3 ячейки — не чётность, а разное время.** В них вместо предмета стоит
  время: `«5-я пара - Основы философии»` vs `«с 18.00 до 21.00 - …»`.
  Это вечерние занятия, их надо разбирать отдельно, а не как чётность.

### Формат текста в ячейке

Предмет может занимать **несколько строк** (4 курс):

```
Иностранный язык
в профессиональной деятельности
Пупкова В.В.
```

Правило разбора: **последняя строка — преподаватель**, всё до неё — предмет.
Преподаватель опознаётся по шаблону «Фамилия И.О.» / «Фамилия Имя» /
`Вакансия`. Проверено на всех парах.

### Чего в файле НЕТ

- **Времени пар нет.** Только номер пары. Время — из файлов звонков.
- **Аудиторий нет.** Появляются только в листке замен.
- **Подгрупп нет** (проверено).
- **Чётность не подписана словами** — она закодирована позицией строки
  (см. выше), а в листке замен указана явно текстом.
- **Подгрупп нет** (проверено: ни «1-ая подгруппа», ни «2-ая»).
- **Аудиторий нет** в очном файле. Аудитория приходит только в заменах.

## 3. Листок замен (`Листок замен.docx`) — главное

### Структура документа

Документ содержит **несколько дней подряд**, каждый — свой блок:

```
ЛИСТОК ЗАМЕН К РАСПИСАНИЮ ОЧНОГО ОТДЕЛЕНИЯ
ФГБОУ ВО «Заполярный государственный университет им. Н.М. Федоровского»
Политехнический колледж
на 24.10.2026, суббота, четная неделя        ← ЗАГОЛОВОК ДНЯ
[таблица 0]
Зам директора по УР                О.И. Трошкина
ЛИСТОК ЗАМЕН К РАСПИСАНИЮ ОЧНОГО ОТДЕЛЕНИЯ
...
на 26.10.2026, понедельник, нечетная неделя  ← ЗАГОЛОВОК ДНЯ
[таблица 1]
Зам директора по УР                О.И. Трошкина
```

**Критично:** заголовок дня и таблица идут **парами**. Номер таблицы в
`doc.tables` соответствует порядку появления в теле документа. Разбирать
надо через `doc.element.body` по порядку, сопоставляя `<w:p>` и `<w:tbl>`.

### Заголовок дня даёт всё сразу

Регулярка: `на (\d{2})\.(\d{2})\.(\d{4}),\s*([^,]+),\s*(\S+)\s+неделя`

Даёт: **дату**, **день недели** и **чётность недели** — явно, текстом.
Это единственное место, где чётность вообще упоминается.

### Таблица замен

4 колонки, первая строка — заголовок:

| Группа | пара | Предмет по расписанию | Чем заменяется |
|---|---|---|---|
| ТЭк-26 | 4 | Обществознание – Кекеева К.А. | Биология – Утева О.В., ауд. 202 |
| ПРк-25 | 1 | ИГ – Кузьмина С.М. | НЕТ ПАРЫ |
| СМк-25 | 1 | НЕТ | Тракторы и автомобили – Барахоев А.В., ауд. 409 |

**Три вида замены** — определяются по паре (было, стало):

| «Предмет по расписанию» | «Чем заменяется» | Смысл | Наша модель |
|---|---|---|---|
| конкретный предмет | другой предмет | замена | `action=replace` |
| конкретный предмет | `НЕТ ПАРЫ` | отмена | `action=cancel` |
| `НЕТ` | предмет | дополнительная пара | `action=add` |

Замены `НЕТ ПАРЫ` — **21 из 84**. Это и есть «занятий нет» по конкретной паре.

### Диапазоны пар

Колонка «пара» может содержать диапазон: `1`, `2`, `1,2`, `2,3`, `3,4`.
Диапазон означает «эта замена действует на обе пары» — разворачивать в
отдельные записи.

### Формат «Чем заменяется»

```
Предмет – Преподаватель, ауд. NNN
```

Разбор: аудитория — в конце после запятой; преподаватель — после
разделителя ` – ` (пробел-тире-пробел); всё до — предмет.

Варианты аудиторий: `ауд. 201`, `спортзал`, `актовый зал`, `см.р`,
`мастерские`.

**Ловушка:** двойная фамилия `Обществознание – Мурашова – Росс А.В.`
ломает наивный `rsplit(' – ', 1)`. Нужно опознавать ФИО по шаблону
(«Фамилия И.О.»), а не просто по последнему дефису.

### Объём (на 23.10.2026)

- Дней в файле: **2** (24.10 суббота — чётная, 26.10 понедельник — нечётная)
- Замен: **84** (34 replace, 29 add, 21 cancel)

**Архива нет.** Файл перезаписывается по тому же URL. Старые версии
доступны только в кэше (`ETag`, `Last-Modified`), но не как отдельные файлы.
→ **Историю должен хранить бот.**

## 4. 🔴 Чётность недели НЕ совпадает с ISO

Это самое важное открытие. Колледж пишет чётность прямо в заголовке
листка замен. Сверка с ISO:

| Дата | День | ISO-неделя | Чётность по ISO | Чётность колледжа | |
|---|---|---|---|---|---|
| 2026-10-24 | суббота | 43 | нечётная | **чётная** | ❌ |
| 2026-10-26 | понедельник | 44 | чётная | **нечётная** | ❌ |

**Обе даты инвертированы.** Гипотеза `parity = (ISO_week + 1) % 2`
подтверждается на обеих:

| Дата | ISO+1 | Совпадает с колледжем |
|---|---|---|
| 2026-10-24 | 44 → чётная | ✅ |
| 2026-10-26 | 45 → нечётная | ✅ |

**Вывод:** в `week_parity()` нужен `parity_offset=1`, либо иной механизм.
Но двух точек мало для уверенности — **нужно накопить больше наблюдений**.

> **Важно:** чётность внутри xlsx (верх/низ ячейки) и чётность в листке замен
> (текст «чётная/нечётная») — это одна и та же система. Мы её связали через
> замены: 2 независимых наблюдения дали `BOT = нечётная`. Значит, когда
> бот вычисляет чётность даты сам, он должен давать тот же ответ, что и
> колледж. Проверка: 26.10.2026 колледж считает **нечётной**; по ISO это
> неделя 44 (чётная), а с `offset=1` → 45 (нечётная) ✅.

## 5. 🔴 Расхождения имён групп

Замены и расписание иногда пишут группы по-разному. Найденные случаи:

| В заменах | В расписании | Причина |
|---|---|---|
| `ЭОК-26` | `ЭОк-26` | регистр буквы |
| `ДОУ - 25` | `ДОУ-25` | лишние пробелы |
| `ЭОф-26` | **нет такой** | опечатка (имелась в виду `ЭО-26ФП`) |

Проверка `ЭОф-26`: в замене указано «ОБиЗР – Боровик И.А.», и у `ЭО-26ФП`
4-я пара понедельника — ровно «Основы безопасности и защиты Родины /
Боровик И.А.». Значит это опечатка, а не новая группа.

**Нужна нормализация:** убрать пробелы, привести к верхнему регистру,
сопоставить с известными группами по «расстоянию» (Левенштейн ≤ 2).

## 7. Заочное отделение

`Заочная форма.docx` — **другая структура**, сессионная:

```
УТВЕРЖДАЮ
Директор колледжа              С.П. Блинова
Расписание занятий заочного отделения ... (26.10.26 – ...)
```

8 таблиц, каждая — неделя с датами:

| день недели | время | ЭО-26з | ПРн-26з | ПР-26з |
|---|---|---|---|---|
| Понедельник 26.10.26 | 18.30-20.00 / 20.10-21.40 | | | |
| Вторник 27.10.26 | ... | | Иностранный язык... | ... |

Отличия: **время задано явно** (18:30–20:00, 20:10–21:40), привязка к
**конкретным датам**, группы с суффиксом `з`.

**Решение:** заочку пока не берём (пользователь: «вуз мы не делаем пока что»,
и заочка — отдельная история). Но структура зафиксирована здесь, чтобы
вернуться.

## 8. Что это значит для бота

### Схема данных

Модель «база + замены» подходит идеально. Важное уточнение: **в базовом
расписании чётность ЕСТЬ**, но закодирована позицией строки в ячейке.

```
BaseLesson:  группа + день недели + номер пары + week_parity → предмет, преподаватель
             week_parity ∈ { EVEN, ODD, BOTH }
             • merged-ячейка           → BOTH
             • верхняя строка split    → EVEN
             • нижняя строка split     → ODD

Substitution: дата + группа + номер пары → replace / cancel / add
              (дата и чётность из заголовка листка замен)
```

Распределение по 704 записям: `BOTH` — 620, `EVEN` — 38+7, `ODD` — 38+8.

### Что меняется в коде

| Было | Стало |
|---|---|
| `parsers/polar.py` (ежедневный `.docx` по ссылке «на DD.MM.YYYY») | `parsers/eios.py`: страница → 3 файла |
| `CollegeLesson` (пары на дату) | `BaseLesson` + `Substitution` |
| Ссылки меняются каждый день | Пути **постоянные**, файлы перезаписываются |
| Дедуп по MD5 содержимого | Достаточно `ETag` / `Last-Modified` |
| Данные только на сегодня-завтра | **Весь семестр** (658 пар) сразу |
| Чётность неизвестна | **Чётность из merge-структуры ячейки** (верх=чёт, низ=нечет) |

### Дедуп через ETag

```
HEAD /upload/timetable.ptk/СПО/Листок замен.docx
→ etag: "6adafcdf-959d"
→ last-modified: Fri, 23 Oct 2026 06:21:19 GMT
```

Можно не качать файл, если `ETag` не изменился. Экономит трафик и время.
Но `ETag` у nginx — это `size-mtime`, так что при перезаписи с тем же
размером и временем он не изменится. Надёжнее: `ETag` + хэш содержимого
при скачивании.

### Поллер

```
раз в N минут:
  1. GET страницу 49960        → извлечь 3 ссылки ПТК
  2. HEAD по каждой           → сравнить ETag
  3. если изменилось:
       скачать → распарсить → заменить данные в БД
       → уведомить подписчиков затронутых групп
  4. если ссылок 0 → тревога «структура страницы изменилась»
```

Замены обновляются **чаще всего** (сегодня в 06:21 UTC). Их стоит
опрашивать чаще, чем базовое расписание (обновлялось 21.10).

26 из 37 групп имеют хотя бы одну пару, зависящую от чётности.

### Алгоритм

```
для каждого листа (курс):
  группы = значения строки 3, колонки C..P
  merged = множество (row, col) вертикальных merge на 2 строки

  для каждой строки r, где в колонке B есть «N пара»:
    day = последний встреченный день из колонки A
    для каждой колонки c с группой:
      top = ячейка(r, c);  bot = ячейка(r+1, c)

      # 1. продолжение предмета: снизу только ФИО
      если bot — одна строка и это ФИО, а top без ФИО:
          → одна запись, parity=BOTH, teacher=bot

      # 2. объединённая ячейка = одна пара на обе недели
      иначе если (r,c) в merged:
          → одна запись, parity=BOTH

      # 3. разъединённая = две пары по неделям
      иначе:
          top → parity=EVEN (чётная)
          bot → parity=ODD  (нечётная)
```

### Разбор текста ячейки

1. Разбить по `\n`, отбросить пустые, схлопнуть пробелы.
2. Если строк несколько и **последняя** похожа на ФИО → это преподаватель,
   остальное — предмет (может быть многострочным).
3. Если строка одна — искать ФИО в конце (`… Мордвин А.О.`) или
   `Вакансия`; иначе весь текст — предмет.
4. Отрезать префикс времени: `«5-я пара - »`, `«с 18.00 до 21.00 - »`
   → в отдельное поле `time_note`.

### Шаблон ФИО

```python
NAME    = r'[А-ЯЁ][а-яё\-]+'
TEACHER = rf'^(?:{NAME}(?:\s*[–-]\s*{NAME})?\s+[А-ЯЁ]\.\s*[А-ЯЁ]?\.?'
          rf'|{NAME}\s+{NAME}|[Вв]акансия)$'
```

Покрывает: `Ивасишина Е.Е.`, `Барахоев А.В` (без точки), `Городиский В..`
(двойная точка), `Мурашова – Росс А.В.` (двойная фамилия), `Вакансия`.

### Подводные камни, найденные на практике

| Проблема | Пример | Решение |
|---|---|---|
| Предмет из 3 строк | `Иностранный язык / в профессиональной деятельности / Пупкова В.В.` | преподаватель = последняя строка |
| ФИО без точки | `Борисенко А.Д` | `\.?` в шаблоне |
| Двойная точка | `Городиский В..` | `[А-ЯЁ]?\.?` |
| Двойная фамилия | `Мурашова – Росс А.В.` | `(?:– NAME)?` |
| «вакансия» строчными в конце | `Геология вакансия` | отдельная регулярка |
| Время в начале | `с 16.20 до 19.40 \n Техническое обслуживание… Мордвин А.О.` | отрезать префикс + ФИО в конце |
| Время в начале слота | `5-я пара - Основы философии` | `time_note` |
| Лист «1 курс » с пробелом | — | `.strip()` при сравнении |
