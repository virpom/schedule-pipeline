# Расписание ПТК — Telegram-бот

Бот для **Политехнического колледжа ЗГУ** (Норильск). Сам следит за сайтом
`polaruniversity.ru`, качает ежедневное расписание (`.docx`), хранит в SQLite и
отдаёт студентам и преподавателям по кнопкам или рассылкой.

## Роли

При первом запуске бот спрашивает, кто ты:

- **🎓 Студент** — выбираешь свою группу (кнопками).
- **👨‍🏫 Преподаватель** — выбираешь себя из списка («Фамилия И.О.»).

Функционал одинаковый; у преподавателя расписание — его пары по всем группам,
и нет кнопки «Картинки».

## Инструкция для студента

### Первый запуск

1. Открой бота и нажми **Start** (или отправь `/start`).
2. Нажми **🎓 Студент**.
3. Выбери **свою группу** кнопками из списка (например, «ТЭ-26ФП»).

Сразу откроется меню. Группу можно поменять в любой момент — кнопка **🎯 Сменить группу**.

### Как пользоваться

| Что нужно | Как сделать |
|---|---|
| Расписание на день | **📅 Сегодня** или **📅 Завтра** |
| Расписание на неделю вперёд | **🗓 Вся неделя** |
| Прошлые дни | **📜 История** → выбери дату |
| Время звонков | **⏰ Расписание звонков** |
| Перемены и обед подробнее | **🕒 Детализация** (кратко → с обедом → полное) |
| Найти занятия по предмету | **🔎 Предмет** → введи название (например, «физика») |
| Найти, где и когда преподаватель | **👨‍🏫 Преподаватель** → введи фамилию |
| Вкл/выкл уведомления о новом расписании | **🔔 Подписаться / Отписаться** |
| Напоминания о начале/конце пары | **🔔 Звонки: режим** (выкл / звонок / звонок+перемена / звонок+обед / всё) |
| Картинка к уведомлению | **🐱 Картинки: вкл/выкл** |
| Сменить группу | **🎯 Сменить группу** |
| Переключиться в преподавателя | **🎭 Сменить роль** |

Быстро задать группу командой: `/group ТЭ-26ФП`.

## Возможности

- 📅 Расписание на **сегодня / завтра / всю неделю**.
- 📜 **История** — прошлые дни (бот подхватывает изменения на сайте).
- 🔎 Поиск **по предмету** (студент — в своей группе, преподаватель — по своим парам).
- 👨‍🏫 Поиск **по преподавателю** (студент: где и когда его найти) / 👥 **по группе** (преподаватель).
- ⏰ **Расписание звонков** — полное, с переменами и обедом (понедельник отличается).
- 🕒 **Детализация** времени: кратко / с обедом / полное.
- 🔔 **Режим звонков** (напоминания): выкл / звонок / звонок+перемена / звонок+обед / всё.
- 🔔 **Подписка** — приходит уведомление, когда выложили новое расписание.
- 🐱 **Картинки** (студенты) — к уведомлению прикладывается случайная картинка дня недели.
- 📨 **Поддержка** — ссылка на чат (настраивает админ).

## Команды (студент/преподаватель)

- `/start` — меню (или выбор роли при первом входе).
- `/group ТЭ-26ФП` — быстро задать группу.

## Для админа

### Статистика и управление
| Команда | Что делает |
|---|---|
| `/admin` | меню админа (кнопками) |
| `/stats` | статистика: всего/активных/подписчиков/преподавателей + раскрытие тегов по группам |
| `/teachers` | список зарегистрированных преподавателей |
| `/chats` | привязанные групповые чаты |
| `/bell` | расписание звонков |
| `/setbell MONDAY I_IV 1 09:25-10:10` | поменять звонок |

### Настройки (на лету, переживают рестарт)
| Команда | Что делает |
|---|---|
| `/settings` | показать настройки |
| `/setpoll 300` | интервал опроса сайта, сек (мин. 10) |
| `/setrate 20` | скорость рассылки, сообщений/сек (до 30) |
| `/setnight 23:00 07:00` | окно ночной паузы опроса (`off` — выключить) |
| `дедлайн` (в `/admin` → Настройки) | час, после которого «не выложено» → «занятий нет» |

### Рассылка
| Команда | Что делает |
|---|---|
| `/broadcast текст` | сообщение всем |
| `/broadcast_teachers текст` | сообщение преподавателям |
| `/broadcast_group ДП-26 текст` | сообщение группе |
| `/notify` | тест уведомления: всем (с подтверждением) / себе (превью) |
| `/notify me` | превью своего расписания |
| `/notify ДП-26` | превью расписания группы |

Все рассылки идут через подтверждение «✅ Отправить / ❌ Отмена» и дросселируются по
`NOTIFY_RATE`, чтобы не упереться в лимиты Telegram.

### Фото
`/admin` → 🖼 Фото → загрузить пачкой (выбрать день → скинуть фото → «Готово»), или
кидать файлы напрямую в папки на сервере.

## Картинки (котята по дням недели)

Папки на сервере: `data/photos/{monday…sunday}/` (в контейнере `/data/photos`).
Бот берёт случайную картинку дня недели и прикладывает к уведомлению о новом
расписании (если у пользователя включено 🐱). Пустая папка → просто текст.

## Логика «занятий нет»

- Файл за дату **выложен** → если у группы/преподавателя нет пар — «Занятий нет» сразу.
- Файла **ещё нет** → «Расписание ещё не выложено ⏳», а после дедлайна (по умолчанию 20:00) — «Занятий нет».
- Если в самом файле написано «Занятий нет. Смотреть расписание на …» — бот показывает эту пометку.

## Запуск

```bash
cp .env.example .env      # вписать BOT_TOKEN и ADMINS
docker compose up -d --build
```

SQLite — `./data/database.db` (volume), фото — `./data/photos/`.

### Переменные окружения (`.env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота от BotFather | — |
| `ADMINS` | Telegram ID админов через запятую | — |
| `SQLITE_PATH` | путь к базе | `database.db` |
| `SCHEDULE_URL` | страница с расписанием | сайт ЗГУ |
| `BASE_URL` | домен сайта | `polaruniversity.ru` |
| `POLL_INTERVAL` | стартовый интервал опроса, сек | 1800 |
| `NOTIFY_RATE` | стартовая скорость рассылки, сообщ/сек | 20 |
| `PHOTOS_PATH` | папка с фото по дням | `/data/photos` |
| `MODE` | `daily` / `permanent` | `daily` |

## Как добавить постоянное расписание (режим `permanent`)

Когда в разделе «Колледж» вместо заглушек `href="#"` появятся реальные ссылки
(«Расписание занятий (очная форма)» и т.д.):

1. **Формат файла** — скорее всего `.xls` (как у бакалавриата) или `.docx`.
2. **Парсер** — новый модуль `parsers/permanent.py` (`.xls` → `pandas.read_excel`,
   `.docx` → переиспользовать `polar.parse_docx`).
3. **Хранение недель** — отдельная таблица `PermanentLesson(week_num, weekday, group, para, …)`
   или раскладка в `CollegeLesson` по датам.
4. **Режим** — `MODE=permanent` + ветка в `tgbot/services/poller.py`.

Куда смотреть: `parsers/polar.py`, `tgbot/services/poller.py`, `common/schedule.py`,
`infrastructure/database/models/`.
