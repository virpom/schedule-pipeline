# Расписание ПТК — Telegram-бот

Бот для **Политехнического колледжа ЗГУ** (Норильск). Сам следит за сайтом
`polaruniversity.ru`, качает ежедневное расписание (`.docx`), хранит в SQLite и
отдаёт по кнопкам или рассылкой подписчикам.

## Что умеет

- 🎯 Выбор своей группы кнопками.
- 📅 Расписание на **сегодня / завтра / всю неделю**.
- 📜 **История** — прошлые дни (если перезаливали/меняли — бот подхватывает).
- 🔎 Поиск **по предмету** — когда был последний раз.
- 👨‍🏫 Поиск **по преподавателю** — где и во сколько его найти (группа, кабинет).
- ⏰ **Расписание звонков** — полное, с переменами и обедом (понедельник отличается).
- 🕒 Три режима отображения времени: **кратко / с обедом / полное**.
- 🔔 Рассылка: когда на сайте выложили новое расписание — бот сам пришлёт его подписчикам.
- Админка: статистика по пользователям и группам, настройки на лету.

## Как пользоваться (студенту)

1. Открой бота и нажми **/start**.
2. Нажми **🎯 Выбрать группу** → выбери свою.
3. Дальше всё кнопками:

| Кнопка | Что делает |
|---|---|
| 📅 Сегодня / Завтра | расписание на день (если пар нет — покажет ближайший) |
| 🗓 Вся неделя | все дни с парами на неделю вперёд |
| 📜 История | прошлые даты, где были пары |
| ⏰ Звонки | полное расписание звонков с переменами и обедом |
| 🕒 Детализация | переключает вид времени: кратко → с обедом → полное |
| 🔎 Предмет | ищет по названию предмета (последние 5 занятий) |
| 👨‍🏫 Преподаватель | ищет по фамилии преподавателя (где и когда его найти) |
| 🔔 Подписаться | включить рассылку нового расписания |
| 🎯 Сменить группу | выбрать другую группу |

### Команды

- `/start` — меню.
- `/group ТЭ-26ФП` — быстро задать группу текстом.

## Для админа

| Команда | Что делает |
|---|---|
| `/stats` | статистика: всего/активных/подписчиков + раскрытие тегов по группам |
| `/settings` | показать настройки (интервал опроса, скорость рассылки, ночь) |
| `/setpoll 300` | интервал опроса сайта, сек (мин. 10) |
| `/setrate 20` | скорость рассылки, сообщений/сек (до 30) |
| `/setnight 23:00 07:00` | окно ночной паузы опроса (`/setnight off` — выключить) |
| `/bell` | показать расписание звонков |
| `/setbell MONDAY I_IV 1 09:25-10:10` | поменять звонок (день, курс, пара, время) |

Ночью (по умолчанию 23:00–07:00) бот сайт не опрашивает — расписание в это время
точно не выложат. Настройки меняются на лету и переживают рестарт.

## Запуск

```bash
cp .env.example .env      # вписать BOT_TOKEN и ADMINS
docker compose up -d --build
```

SQLite лежит в `./data/database.db` (volume). Звонки и настройки сеяться автоматически.

### Переменные окружения (`.env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота от BotFather | — |
| `ADMINS` | Telegram ID админов через запятую | — |
| `SQLITE_PATH` | путь к базе | `database.db` |
| `SCHEDULE_URL` | страница с расписанием | сайт ЗГУ |
| `BASE_URL` | домен сайта | `polaruniversity.ru` |
| `POLL_INTERVAL` | стартовый интервал опроса, сек | 1800 |
| `NOTIFY_RATE` | стартовая скорость рассылки, сообщ/сек | 20 |
| `MODE` | `daily` / `permanent` | `daily` |

## Локально

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
BOT_TOKEN=... ADMINS=... .venv/bin/python main.py
```

## Как добавить постоянное расписание (режим `permanent`)

Когда в разделе «Колледж» вместо заглушек `href="#"` появятся реальные ссылки
(«Расписание занятий (очная форма обучения)» и т.д.), делаем так:

1. **Смотрим формат файла.** Скорее всего `.xls` (как у бакалавриата) или `.docx`
   (как сейчас). Скачай и определи структуру таблицы: строки/колонки, где группы,
   где пары, есть ли «недели» (чётная/нечётная, «1-я/2-я»).

2. **Пишем парсер** — новый модуль `parsers/permanent.py`:
   - `.xls` → `pandas.read_excel` (добавь `pandas` + `xlrd`/`openpyxl` в `requirements.txt`);
   - `.docx` → `python-docx` уже стоит, переиспользуй `polar.parse_docx`.
   - На выходе — те же записи `{group, para, subject, teacher, room}` + неделя/день недели.

3. **Храним недели.** Постоянное расписание повторяется по неделям, а не по датам:
   - либо отдельная таблица `PermanentLesson(week_num, weekday, group, para, …)`;
   - либо проще — раскладывать недели в конкретные даты в существующую `CollegeLesson`.

4. **Переключаем режим.** `MODE=permanent` в `.env` + админ-команда `/mode daily|permanent`.
   В `tgbot/services/poller.py` добавить ветку: `permanent` → парсим основной файл.

5. **Миграция.** Ежедневные `.docx` исчезнут с сайта; бот продолжит отдавать
   «сегодня/завтра» уже из постоянной таблицы. БД — `./data/database.db`.

Куда смотреть: `parsers/polar.py`, `parsers/permanent.py` (новый),
`tgbot/services/poller.py`, `config.py`, `infrastructure/database/models/college_lesson.py`.

## Стек

`aiogram 3` · `SQLAlchemy 2` (async) · `SQLite` · `python-docx` · `BeautifulSoup` · `aiohttp`.
