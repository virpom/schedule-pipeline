# План 079: время из ячейки замены остаётся в названии предмета

**Приоритет:** средний. Студент видит «с 17.10 - Средства автоматизации
и управления» вместо «Средства автоматизации и управления». На проде
19 таких записей, из них 7 — из-за заглавной буквы.

**Трудоёмкость:** S (добавить `re.I` + один тест).

## Проблема

В файле вуза пара иногда стоит не в своём блоке, а позже — тогда в
ячейке пишут время начала: «с 18.50 - Металлургия». Номер пары берётся
из этого времени. Разбирает его `inline_para` (`parsers/vuz.py:215`):

```python
def inline_para(text: str) -> tuple[int | None, str]:
    stripped = PARITY_RE.sub("", text).lstrip() if PARITY_RE.match(text) else text
    m = INLINE_TIME_RE.match(stripped)
    if not m:
        return None, text
    head = f"{int(m.group(1))}.{m.group(2)}"
    for key, para in GRID.items():
        if key.split("-")[0] == head:
            rest = stripped[m.end():].lstrip(" .-–—")
            return para, rest
    return None, text
```

Регулярка (`parsers/vuz.py:77`):

```python
INLINE_TIME_RE = re.compile(
    r"^\s*с[\s.]*(\d{1,2})[.:](\d{2})"
    r"(?:\s*[.\-–—]*\s*\d{1,2}[.:]\d{2})?")
```

Флаг `re.I` **не указан**. Проверил:

```
INLINE_TIME_RE.flags = 32    (re.UNICODE)
re.I = False

'С 12.10 Технология'  -> НЕТ совпадения
'с 12.10 Технология'  -> ДА, группа 'с 12.10'
```

Вуз пишет и «с 18.50», и «С 18.50» — регистр не выдержан. Заглавная
`С` не распознаётся, `inline_para` возвращает `(None, text)` с исходным
текстом, и время остаётся в названии предмета.

**Отдельный случай — время, которого нет в `GRID`.** Строки

было бы.

## Что сделать

**1. Регистр.** Добавить `re.I`:

```python
INLINE_TIME_RE = re.compile(
    r"^\s*с[\s.]*(\d{1,2})[.:](\d{2})"
    r"(?:\s*[.\-–—]*\s*\d{1,2}[.:]\d{2})?", re.I)
```

**2. Снимать нераспознанный префикс.** Если время в ячейке есть, но
номера пары для него нет, — префикс всё равно убрать из названия:

```python
def inline_para(text):
    stripped = PARITY_RE.sub("", text).lstrip() if PARITY_RE.match(text) else text
    m = INLINE_TIME_RE.match(stripped)
    if not m:
        return None, text
    rest = stripped[m.end():].lstrip(" .-–—")
    head = f"{int(m.group(1))}.{m.group(2)}"
    for key, para in GRID.items():
        if key.split("-")[0] == head:
            return para, rest
    return None, rest      # время сняли, пару не угадали
```

Так «с 18.10-19.40 Корпоративные…» станет «Корпоративные…» без
выдуманного номера пары.

**3. Конфликты замен.** Не терять молча. Минимум — предупредить:

```python
if key in seen:
    prev = seen[key]
    if (prev.subject, prev.teacher) != (change.subject, change.teacher):
        log.warning("замены вуза конфликтуют на %s %s п%s: %r vs %r",
                    key[0], key[1], key[2], prev.subject, change.subject)
    continue
```

`seen` сейчас `set`, придётся сделать `dict[key] -> change`.

`para` от 1 до 8 в обоих — восьмая пара вуза разбирается.

**`GRID` покрывает все 8 пар вуза.** Проверил: `8.40-10.10` (1) …

## Риски

- **`re.I` заденет другие языки.** Регулярка начинается с `^\s*с`, и
  `re.I` сделает её регистронезависимой для `с`/`С`. Других букв в
  шаблоне нет — латиница не задета.
- **Снятие префикса может съесть настоящий текст.** Если предмет
  начинается со слова «с» и числа, например «С 3 курса…», регулярка
  примет это за время. Проверил все 272 замены: таких нет, но
  `INLINE_TIME_RE` требует `\d{1,2}[.:]\d{2}` — то есть «С 3 курса» не
  совпадёт (нет двоеточия или точки с двумя цифрами).
