# План 007: студент вуза не должен видеть обед колледжа

> **СДЕЛАНО 27.10.2026** (коммит `abef329`).
>
> Три места: `format_day`, и две копии в `bell.py`. Ветка на `I_IV`
> больше не срабатывает для `VUZ`. Колледж свой обед сохраняет — при
> неопределённом курсе `cg` бывает `None`, и `I_IV` остаётся разумным
> умолчанием.
>
> Воспроизведено до правки: `10:20–11:05 / 🍽 11:30–11:55 / 11:15–11:50`.

**Приоритет:** седьмой. Правка в одну строку, чинит видимую кривизну.

**Трудоёмкость:** S (одна строка в двух файлах + 1 тест).

## Проблема

`common/schedule.py:233`:

```python
lunch = lunches.get((dt, cg)) or lunches.get((dt, "I_IV"))
```

`cg` для группы вуза — это `VUZ` (так её возвращает
`course_group_from_group`). В таблице `bell_lunch` **ноль строк** с
`course_group='VUZ'`, поэтому `lunches.get((dt, "VUZ"))` возвращает
`None`, и срабатывает запасная ветка — **обед колледжа первого курса**.

Обед `I_IV` — это `11:30–11:55`, `position='inside'`, `para=2`.
Сетка звонков вуза на 2-й паре — `10:20–11:05 / 11:15–11:50`.

**Воспроизведено:**

```
2) 10:20–11:05 / 🍽 11:30–11:55 / 11:15–11:50  Математический анализ (прак)
```

Время идёт не по порядку: 11:05 → 11:30 (обед) → 11:15.

Тот же баг в `tgbot/services/bell.py:52` (напоминания о звонках):

```python
lunch = lunches.get((dt, cg)) or lunches.get((dt, "I_IV"))
```

## Почему запасная ветка вообще нужна

Для колледжа `cg` вычисляется из курса группы (`I_IV` или `II_III`).
Если у группы курс не определён, `cg` может быть `None` — тогда
`I_IV` служит разумным умолчанием. Для вуза это умолчание неверно:
у вуза своя сетка и своего обеда нет вообще.

## Что сделать

### 1. Не подставлять колледжеский обед для вуза

В `common/schedule.py:233`:

```python
lunch = lunches.get((dt, cg))
if lunch is None and cg != VUZ_GROUP:
    lunch = lunches.get((dt, "I_IV"))
```

`VUZ_GROUP` уже импортирован в этом модуле (используется в строке 386).
Проверить, что импорт есть в шапке.

В `tgbot/services/bell.py:52` — то же самое. Там `VUZ_GROUP` может
потребовать импорта; проверить.

### 2. Тот же фикс для звонков

`bell.py:84` содержит ещё одну копию:

```python
lunch = lunches.get((dt, _cg(lunch_lesson.group))) or lunches.get((dt, "I_IV"))
```

Заметить: `bell.get(...)` в строках 52 и 63 тоже имеет запасную ветку
на `I_IV`. Для вуза она опасна так же, но сейчас маскируется тем, что
сетка `VUZ` полная (8 пар). Оставить как есть — не расширять правку,
но записать в комментарий.

### 3. Тест

В `tests/test_schedule_logic.py` (там уже есть тесты `format_day`):

```python
def test_vuz_does_not_show_college_lunch():
    """Обед колледжа не должен попадать в сетку вуза.

    У вуза в bell_lunch нет своих обедов, и запасная ветка на I_IV
    вставляла 11:30–11:55 между 11:05 и 11:15 — время шло не по порядку.
    """
    bell = {("OTHER", VUZ_GROUP, 2): BS(2, "10:20", "11:05", "11:15", "11:50")}
    lunches = {("OTHER", "I_IV"): Lunch("11:30", "11:55", para=2)}
    slot = Slot(2, "Математический анализ", "Фидарова М.Г.", "", group="ГД-26@vuz")
    text = format_day(date, [slot], bell, lunches, detail="full", meta="group")
    assert "🍽" not in text
```

## Риски

- **Колледж не сломать.** Для колледжа `cg` — это `I_IV` или `II_III`,
  и запасная ветка остаётся как была. Проверить тестами
  `test_schedule_logic.py` и живым прогоном одного дня колледжа.
- **`position='after'`** у `II_III` — эта ветка тоже не должна
  срабатывать для вуза. Правка в одной строке закрывает оба случая.
