# План 095: «Неделя» молча пропускает дни без пар

**Приоритет:** средний. У всех 129 групп в неделе есть дни без пар, и
они **не появляются в списке вовсе** — студент не отличает «в этот день
пар нет» от «в этот день я не посмотрел».

**Трудоёмкость:** S (~8 строк).

## Проблема

`_week_text` (`user.py:722`) собирает дни из того, что вернула выборка:

```python
lessons = await _user_lessons_range(repo, user, start, end)
by_date: dict[datetime.date, list] = {}
for l in lessons:
    by_date.setdefault(l.date, []).append(l)
entries = [(d, by_date[d]) for d in sorted(by_date)]
return format_week(entries, bell, lunches, user.bell_detail, meta, show_rov, gcg)
```

`by_date` содержит **только дни, где есть хотя бы одна пара**. День без
пар в `entries` не попадает — и `format_week` про него не знает.

`format_week` (`common/schedule.py:328`) честно рисует то, что дали:

```python
if not entries:
    return "На этой неделе расписания пока нет 📭"
return "\n\n".join(format_day(d, les, bell, lunches, detail, meta, show_rov, group_course_group) for d, les in entries)
```

Пустой список дней он бы нарисовал как «Занятий нет 🙌» — но такого
списка ему не передают.

## Что видит студент

Проверил на живом коде: неделя, где понедельник с парами, вторник
отменён, среда пуста, четверг с парами.

```
📅 Понедельник, 26 октября
1) пара 1  Математика
Иванов И.И. · 101

📅 Вторник, 27 октября
1) ~~пара 1  Физика~~  ❌ отменено

📅 Четверг, 29 октября
1) пара 1  История
Сидоров С.С. · 103
```

**Среды нет вообще.** Студент видит, что понедельник, вторник и
четверг идут подряд, и не знает, пропущена среда или в ней пар нет.

Заметьте асимметрию: **вторник показан** — потому что отменённая пара
создаёт слот (`action=SUB_CANCEL`). То есть день, где занятий **не
будет**, виден, а день, где их **не было**, — нет.

## Насколько это часто

Замерил на проде за неделю 26.10–01.11:

```
дней с парами из 7:   групп
        1              4
        2              9
        3             19
        4             16
        5             63
        6             18
        7              0     <- ни одной группы
```

**129 групп, и ни у одной нет пар во все семь дней.** В среднем 4.3
дня из 7 — то есть **2–3 дня в неделю пропадают у каждого студента**.

## Что сделать

Заполнить пропуски пустыми списками:

```python
entries = []
d = start
while d <= end:
    entries.append((d, by_date.get(d, [])))
    d += datetime.timedelta(days=1)
```

Тогда `format_week` вызовет `format_day(d, [], ...)` для пустого дня, а
тот уже умеет это рисовать (`empty_day` → «Занятий нет 🙌»).

**Длину сообщения замерил — не проблема.** Пустой день рисуется
`empty_day` и занимает **41 символ** (`📅 Среда, 28 октября` + пустая
строка + `Занятий нет 🙌`).

Прогнал реальные данные через `format_day` для трёх плотных групп за
26.10–01.11:

```
ГИ-24@vuz   23 пары, 6 дней   сейчас ~1633 -> станет ~1682  запас 2414
СМк-25      19 пар,  5 дней   сейчас ~1316 -> станет ~1414  запас 2682
ЭОф-24      19 пар,  5 дней   сейчас ~1415 -> станет ~1513  запас 2583
```

Даже худшая группа после правки остаётся вдвое ниже лимита 4096.
План 058 («Проверено и снято: переполнение 4096 символов») считал ~102
символа на пару — сходится: 23 пары дают 1633.

Так что переполнение этим планом **не приближается**. Опасение, что
правка «включит» другую проблему, не подтвердилось: у `ГИ-24@vuz`
7 пар в один день (проверил, это максимум на проде), но за неделю всё
равно 23 пары.

## Проверено и признано корректным

**`format_week` рисует отмены правильно.** Он зовёт `format_day`, а тот
проверяет `action == SUB_CANCEL` и зачёркивает пару
(`common/schedule.py:248`). Отменённый день в «Неделе» выглядит так же,
как в экране дня — расхождения нет.

**Отменённый день попадает в неделю, а пустой — нет.** Это следствие
одной и той же причины: `by_date` строится по слотам, а слот отмены
создаётся. Логика не сломана — просто неполна.

**`format_week` не принимает `merge_groups`.** Это
[план 076](076-week-screen-no-merge.md) — у преподавателя поток не
склеивается. Не дублирую.

**Скользящие 7 дней вместо пн–вс.** Это
[план 058](058-week-screen-ux.md). Правка из этого плана не меняет
границы окна — только заполняет пропуски внутри него.

## Риски

- **Сообщение станет длиннее на 1–3 пустых дня.** Замерено: худшая
  группа на проде вырастает с 1633 до 1682 символов при лимите 4096.
  Не риск.
- **Пустые дни могут выглядеть шумно.** Семь заголовков «Занятий нет»
  подряд — хуже, чем пропуск. Возможно, стоит рисовать пустой день
  одной строкой («Ср 28.10 — занятий нет»), а не полным блоком. Но это
  уже дизайн; минимальная правка — просто заполнить пропуски.
