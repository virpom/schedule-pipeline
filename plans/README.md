### Латентные баги, которые проявятся с редактором вуза

Три находки сейчас **недостижимы**: редакторы есть только у `ДП-26`
(колледж), а баги касаются `@vuz`-групп. Записать, чтобы не потерять.

1. **`delete_slot` без `weeks`** (`base_lesson.py:92`, дефолт `""`).
   Оба вызова (`editor.py:508`, `:852`) не передают его. Для вуза
   (1334 пары с непустыми `weeks`) удалит только строки без недель —
   пара останется в расписании.

2. **`get_day` без `week`** (`editor.py:363`). Для вуза на один слот
   бывает несколько строк с разными неделями (на проде **419 таких
   слотов**). `next(...)` возьмёт первую попавшуюся, и староста
   отредактирует не ту неделю.

3. **`_merge_para_clash` склеивает подгруппы** — на проде **5 слотов**,
   где физкультура и язык идут в одной строке через `/`. Студент не
   понимает, какой предмет его. Ограничение источника: подгрупп в
   данных нет.

## Что проверено и признано НЕ проблемой

Записано, чтобы не переаудитить в следующий раз.

- **Пароли и токены в коде** — нет. `.env` в `.gitignore`, `.env.example`
  с пустыми значениями. (Отдельно: `docs/ROADMAP.md:73` фиксирует, что
  токены когда-то светились в выводе команд и не ротированы — это
  отслеженный долг, не новая находка.)
- **Prompt injection** — не найдено. Сплошной поиск по `.py/.md/.txt/.yml`.
- **Подделка `callback_data`** (`teacher:`, `group:`) — позволяет смотреть
  чужое расписание, но расписание публичное. Не проблема.
- **4 обработчика админки без `_is_admin`** — недостижимы: состояние FSM
  ставится только после проверки прав в других обработчиках.
- **4 обработчика редактора без `editor_group`** — работают только внутри
  FSM-состояния, которое ставится после проверки.
- **Индексы БД** — основные запросы используют индекс (`EXPLAIN QUERY PLAN`
  проверен на боевой БД).
- **Логика ночного окна** `_in_night` — все 7 граничных случаев верны.
- **Часовой пояс контейнера** — `Asia/Krasnoyarsk`, сдвиг +7 верный.
- **Обрезка длинных полей** — `subject` режется до 128 при колонке 256,
  но самый длинный в базе 130 символов; реальных потерь нет.
- **Звонки и обеды колледжа** — данные внутренне согласованы (обед ровно
  в перерыве 2-й пары для обоих потоков, будни и понедельник).

  commit в конце. Падение откатывает всё. (В отличие от `replace_date`.)
- **`_merge_para_clash`** — не теряет данные, а склеивает две подгруппы
  в одну строку. Неоднозначно для студента, но это ограничение источника.
- **`alerts.py`** — сам модуль корректен, 7 тестов покрывают

- **`migrations_runner.py`** — корректно обрабатывает легаси-БД без

- **Цепочка миграций** — линейна, полна, прод на `0006_action`.
- **`get_or_create_user`** — один UPSERT с `returning`, не два запроса.
- **Дубли звонков у преподавателя** — защищены ключом `is_sent`.

- **Экран дня — 8 запросов, неделя — 3.** Терпимо.
- **Фото** — 65 файлов, работают, 15 подписчиков.
