# План 094: редактор не показывает, что пара отменена

> **СДЕЛАНО 27.10.2026** (коммит `59ead0a`). `action` проверяется
> первым: отмена — «❌ отменено», замена остаётся с 🔄.

**Приоритет:** средний. Староста ставит отмену, возвращается на экран
дня и видит обычную пару со значком 🔄 — то есть **не может проверить
свою же правку**. Студент при этом видит «❌ отменено».

**Трудоёмкость:** S (~5 строк).

## Проблема

`sub_day_text` (`editor.py:220`) собирает список пар сам, без
`format_day`, и смотрит только `changed`:

```python
for s in slots:
    meta = " · ".join(x for x in (s.teacher, s.room) if x)
    flag = " 🔄" if s.changed else ""          # <- action не смотрит
    lines.append(f"<b>{s.para})</b> {s.subject}{flag}")
```

А `get_day_slots` для отменённой пары ставит `changed=True` **и**
`action=SUB_CANCEL` (`schedule_layer.py:77`). Первого флага достаточно,
чтобы попасть в ветку «замена», второй теряется.

## Что видит староста и что студент

Проверил на живом коде, одна и та же пара:

**Экран редактора** (`sub_day_text`):
```
📅 Понедельник, 26 октября
🔴 нечётная неделя

1) Математика 🔄
      Иванов И.И. · 101

Нажми на пару, чтобы поставить замену 👇
```

**Экран студента** (`format_day`):
```
📅 Понедельник, 26 октября

1) ~~пара 1  Математика~~  ❌ отменено
```

Староста видит «замена», студент — «отмена». Одно и то же состояние
описано по-разному в двух местах.

## Почему это мешает работе

Староста ставит отмену пары → возвращается на день → видит «Математика
🔄». Он не может отличить:

- «я отменил пару» (сделано);
- «я заменил пару, но не ввёл новый предмет» (недоделано).

Обе ситуации выглядят одинаково. При этом `cb_sub_slot` на этом же
дне **показывает правильно**:

```python
if sub.action == SUB_CANCEL:
    text += "Замена: ❌ <b>отменена</b>\n"
```

То есть нажал на пару — увидел правду; вернулся в список — правда
пропала.

## Где ещё теряется `action`

Проверил все места, где читается `Slot.changed`:

| Место | Смотрит `action`? |
|---|---|
| `editor.py:113` `paras_kb` | нет, но это **базовое** расписание — отмен там не бывает |
| `editor.py:234` `sub_day_text` | **нет** — этот дефект |
| `editor.py:254` `preview_text` | да, передаёт `action=s.action` в `format_day` |
| `editor.py:585` `cb_sub_slot` | да, проверяет `sub.action == SUB_CANCEL` |
| `editor.py:157` `sub_slots_kb` | да — `"❌ отменена"` |
| `notify_edits.py:53` `_slots_text` | нет — это [план 070](070-notify-cancel-looks-like-edit.md) |

Значит незакрытых мест два: `sub_day_text` (здесь) и
`notify_edits._slots_text` (план 070). Остальное корректно.

## Что сделать

```python
for s in slots:
    meta = " · ".join(x for x in (s.teacher, s.room) if x)
    if getattr(s, "action", "") == SUB_CANCEL:
        lines.append(f"<b>{s.para})</b> <s>{s.subject}</s> ❌ <i>отменено</i>")
    else:
        flag = " 🔄" if s.changed else ""
        lines.append(f"<b>{s.para})</b> {s.subject}{flag}")
    if meta:
        lines.append(f"      {meta}")
```

`SUB_CANCEL` в `editor.py` **уже импортирован** — используется в
`sub_slots_kb:157` и `cb_sub_slot`. Проверил, дополнительный импорт не
нужен.

**Альтернатива, которая лучше:** заменить ручную сборку на
`format_day`, как это уже сделано в `preview_text`. Тогда редактор и
студент физически не смогут разойтись. Но это большая правка (у
`format_day` другой формат заголовка и есть «Нажми на пару» внизу),
поэтому в этом плане — минимальный вариант.

## Проверено и признано корректным

**`sub_slots_kb` различает отмену.** `if sub and sub.action ==
SUB_CANCEL: label = f"{p}) ❌ отменена"` — кнопка честная.

**`preview_text` не врёт.** Передаёт `action=s.action` в `format_day`,
поэтому предпросмотр показывает ровно то, что увидит студент —
включая зачёркивание. Комментарий в функции это и объясняет: «Раньше
экран собирал текст своей рукой и расходился с реальным».

**`paras_kb` проверять не надо.** Он рисует базовое расписание
(`base_lesson`), где `action` не существует по определению — отмены
живут в `substitution`.

## Риски

- **Формат `<s>` в Telegram.** Зачёркивание поддерживается
  (`parse_mode=HTML`), `format_day` его уже использует — проверено на
  живом рендере выше.
- **`getattr` вместо прямого доступа.** `Slot` имеет `__slots__` с
  полем `action` всегда, поэтому `s.action` безопасен. В плане оставил
  `getattr` для единообразия с `common/schedule.py:248`.
