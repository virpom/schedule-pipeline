# План 162: кривая ссылка поддержки ломает главное меню всем

> **СДЕЛАНО 27.10.2026** (коммит `0101056`).
>
> `_url` подключён в `SETTINGS["support"]` вместо `lambda t: (t,)`.
>
> Строже предложенного сниппета: одного префикса мало — «https://» без
> хоста Telegram тоже отбивает, поэтому проверяется ещё и непустой
> остаток после схемы. Пустая строка (и строка из одних пробелов)
> остаётся способом убрать кнопку.

**Приоритет:** высокий по последствиям. Одна опечатка админа — и
**ни один студент не может открыть меню**, пока он же её не исправит,
причём исправить нечем: `/settings` открывается из того же меню.

**Трудоёмкость:** S (~6 строк).

## Что происходит

`/admin` → «Настройки» → «Ссылка поддержки» → ввод текста.
`SETTINGS["support"]` (`admin.py:940-941`):

```python
"support": _Setting(AdminState.set_support, "Отправь ссылку на группу поддержки:",
                    ("support_link",), lambda t: (t,), "Ссылка поддержки: {}"),
```

`lambda t: (t,)` — **парсер без единой проверки**. Сравни с соседями:

```python
"poll":  _num(t, 10, 86_400)      # диапазон
"rate":  _rate                    # 0 < v <= 30
"night": _night                   # два валидных HH:MM
```

Любой текст сохраняется в `setting.support_link` как есть:

```
'abc'                    -> сохранится
'ftp://x'                -> сохранится
'javascript:alert(1)'    -> сохранится
''                       -> сохранится
```

## Что ломается

`user.py:151-152` — кнопка в главном меню:

```python
if support_link:
    rows.append([InlineKeyboardButton(text="📨 Поддержка", url=support_link)])
```

Telegram Bot API принимает в `url` только `http://`, `https://` и
`tg://`. На всё остальное отвечает `BadRequest: BUTTON_URL_INVALID` —
и **отклоняет сообщение целиком**.

`_render_menu` (`user.py:209-212`) отдаёт эту клавиатуру:

```python
return menu_text(user), menu_kb(user, s["support_link"], is_editor)
```

Её используют **9 обработчиков** — `start:410`, `cb_menu:428`,
`cb_role_switch:535`, `cb_unit_*:592`, `cb_unit_*:604`, `cb_teacher:634`,
`cb_menu:642`, `cb_hist_date:840`, `group_answer:891`. Все они
перестают отвечать.

## Почему это не «ну админ исправит»

**Глобального обработчика ошибок нет** (план 022). Исключение
`BadRequest` из `send_message` уходит в лог, а студент не получает
**ничего** — ни меню, ни сообщения об ошибке.

**Админ тоже заперт снаружи.** `/admin` — команда, она работает, но
кнопка «⚙️ Настройки» живёт в главном меню, которое падает. Команды
`/setrate`, `/setpoll`, `/setnight`, `/setvuzanchor` есть, а
`/setsupport` — **нет**. Проверил список зарегистрированных команд:

```
admin, bell, broadcast, broadcast_group, broadcast_teachers, chats,
group, notify, setbell, setgroup, setnight, setpoll, setrate,
settings, setvuzanchor, stats, teachers
```

`settings` — это, вероятно, `settings_cmd:313`, который показывает
`_settings_text`, но не даёт изменить ссылку. Значит единственный путь
исправления — прямой SQL по базе.

## Что сделать

**Проверять URL при вводе:**

```python
def _url(text: str) -> tuple[str, ...]:
    value = text.strip()
    if value and not value.startswith(("http://", "https://", "tg://")):
        raise ValueError
    return (value,)
```

и подставить в `SETTINGS`:

```python
"support": _Setting(AdminState.set_support, "Отправь ссылку на группу поддержки:",
                    ("support_link",), _url, "Ссылка поддержки: {}"),
```

Пустая строка остаётся допустимой — это способ убрать кнопку совсем
(`if support_link` её и так скрывает).

**Подстраховать `menu_kb`** — не строить кнопку с заведомо битым URL:

```python
if support_link.startswith(("http://", "https://", "tg://")):
    rows.append([InlineKeyboardButton(text="📨 Поддержка", url=support_link)])
```

Это спасает от уже сохранённого мусора: правка в `_url` чинит только
новый ввод.

**Оба пункта нужны.** Первый не пускает мусор в базу, второй не даёт
уже записанному мусору уронить меню.

## Проверено и признал корректным

**`if support_link` уже отсекает пустую строку.** Если ссылка не
задана (`DEFAULTS["support_link"] = ""`), кнопки нет и меню работает.
На проде ссылка заполнена и валидна:
`https://t.me/+zavx3TI9FRtmODM6`.

**Остальные настройки валидируются.** `_num` проверяет границы,
`_rate` — диапазон, `_night` — формат обоих времён через
`time.fromisoformat`. `support` — единственная без проверки.

**`/setnight` и `/setrate` дублируют валидацию** в командах и в FSM —
это не дефект, а две точки входа.

**Дедлайн 18 на проде, 20 в `DEFAULTS`** — не баг: админ менял
значение, дефолт остался прежним.

**Ночная пауза 23:00–07:00 активна по умолчанию.** Проверил: ключей
`night_start`/`night_end` в `setting` нет, работает `DEFAULTS`. Это
осознанно и полезно — ночью расписание не меняется, дёргать сайт
незачем. В `/settings` админ видит это значение.

## Риски

- **`_url` отвергнет `mailto:` и другие схемы.** Telegram их и так не
  принимает в `url` кнопки, так что отказ корректен.
- **Правка `menu_kb`** — вторая линия, она молча скрывает кнопку. Если
  админ введёт битую ссылку в обход валидации (например через SQL),
  он не увидит ошибки, только пропавшую кнопку. Это лучше падения
  меню у 246 человек.
- **`https://` без хоста** проходит проверку `startswith`, но
  Telegram может отклонить. Полная валидация через `urllib.parse`
  надёжнее, но для одной кнопки достаточно префикса.
