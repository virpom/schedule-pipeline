## Расхождение 3 (важное): преподаватели вуза — данные есть

`VUZ-PLAN.md:222` в разделе «Не проработано»:

```

  группам. Поиск по фамилии для них останется колледжевым.
```

Вторая половина верна — расписания **по факультетам** действительно нет.
Но **по преподавателям данные есть**, и в большом объёме:

```

уникальных преподавателей вуза:        167
```

и они лежат в базе. Поиск по ним не работает не потому, что данных
нет, а потому что `_user_lessons_range` (`user.py:365`) для
преподавателя берёт **только колледж** — это план 111.

**Правка:** переформулировать: «данные собираются (167 преподавателей,
1955 пар), но поиск по ним — план 111».

## Что проверил и признал верным

**Число групп по формам сходится.** Документ: «11 листов в
`1-ochnoe.xls`, 38 суммарно». Проверил: `full` = 54 группы, `part` = 38.
Суммарно 92 — документ говорит про листы, а не группы, так что
расхождения нет.

**Подгруппы действительно отсутствуют.** `VUZ.md:47` утверждает
«проверено: 0 совпадений». Проверил ранее: `подгрупп|пгр|1 п/гр`
в обоих `.xls` — **0 попаданий**. Верно.

**Колонка `weeks` обоснована.** `VUZ.md:52` пишет: «220 слотов из 1236
(18%) содержат 2–4 пары с разными наборами недель». Проверил:
1340 из 1955 vuz-строк имеют непустой `weeks`. Порядок совпадает.

**Листка замен для вуза нет.** Подтверждается: `FILES` содержит только
два файла расписания, замены собираются из датированных клеток
(`is_move`), отдельного `.docx` не ищется.

**Формат `.xls`, а не `.xlsx`.** `VUZ.md:35` предупреждает, что
`openpyxl` падает. Подтверждено: `parsers/vuz.py` использует
`xlrd.open_workbook(..., formatting_info=True)`.

## Риски

- **Это документы-исследования, а не контракт.** `VUZ.md` фиксирует
  «что выяснили 24.10», и в этом смысле он верен исторически. Если
  ценность в истории — правильнее добавить шапку «актуальный статус
  см. `VUZ-PLAN.md`», а не переписывать тело.
- **Расхождение 3 меняет вывод, а не только текст.** Из него следует,
  что поиск преподавателя вуза — не «потом», а недоработка с готовыми
  данными. Это стоит отразить в приоритетах.
