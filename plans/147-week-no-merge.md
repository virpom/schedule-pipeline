# План 147: неделя преподавателя не склеивает потоковые пары

> **СДЕЛАНО 27.10.2026** (коммит `ebee92a`).
>
> `format_week` получил `merge_groups` и прокидывает его в
> `format_day`; `_week_text` ставит флаг для преподавателя тем же
> `_is_teacher`, что и экран дня.

**Приоритет:** средний. Преподаватель видит одну и ту же пару по-разному
на двух экранах — и в неделе получает шесть строк вместо одной.

**Трудоёмкость:** S (одна строка).

## Проблема

`_merge_groups` (`common/schedule.py:170`) склеивает пары одного
преподавателя на один слот: физкультура идёт потоком, шесть групп,
один преподаватель, одна пара. Без склейки он видит шесть разных пар.

Включается флагом `format_day(..., merge_groups=True)`. Проверил, кто
его ставит:

```
user.py:392        merge_groups=is_teacher      <- экран дня
tests/...          merge_groups=True
```

**`format_week` (`:328`) флаг не передаёт вообще:**

```python
def format_week(entries, bell, lunches, detail=DETAIL_BRIEF, meta="teacher",
                show_rov=True, group_course_group=None) -> str:
    if not entries:
        return "На этой неделе расписания пока нет 📭"
    return "\n\n".join(format_day(d, les, bell, lunches, detail, meta,
                                  show_rov, group_course_group) for d, les in entries)
```

У `format_day` параметр `merge_groups` идёт **после**
`group_course_group`, и в вызове его нет — значит всегда `False`.

## Проверил на живых данных

`Бацунов С.Н.`, 27.10, пара 1 — шесть групп потока:

```
ИП-24@vuz   Прикладная физическая культура
ИС-24@vuz   Прикладная физическая культура
ИЭ-24@vuz   Прикладная физическая культура
СА-24@vuz   Прикладная физическая культура
СМ-24@vuz   Прикладная физическая культура
ЭКк-26      Обществознание
```

**Экран дня** (`merge_groups=True`) — три строки:
```
1) 08:40–10:10  Прикладная физическая культура
1) 08:40–10:10  Прикладная физическая культура (лек,прак)
1) 09:00–10:35  Обществознание
```

**Экран недели** — шесть строк:
```
1) 08:40–10:10  Прикладная физическая культура
1) 08:40–10:10  Прикладная физическая культура (лек,прак)
1) 08:40–10:10  Прикладная физическая культура (лек,прак)
1) 08:40–10:10  Прикладная физическая культура
1) 08:40–10:10  Прикладная физическая культура
1) 09:00–10:35  Обществознание
```

Первые пять — один и тот же поток. Склейка не сработала.

## Почему это заметно

Преподаватель открывает «Неделю» и видит, что пара 1 повторяется пять
раз. Выглядит как ошибка расписания — хотя в «Дне» всё правильно.

Обратная сторона: если бы он не смотрел «День», он бы вообще не знал,
что склейка существует.

## Что сделать

Передать флаг. Но `format_week` не знает, преподаватель это или
студент — параметра нет. Значит либо добавить:

```python
def format_week(entries, bell, lunches, detail=DETAIL_BRIEF, meta="teacher",
                show_rov=True, group_course_group=None, merge_groups=False):
    ...
    return "\n\n".join(format_day(d, les, bell, lunches, detail, meta, show_rov,
                                  group_course_group, merge_groups) for d, les in entries)
```

и передавать `merge_groups=is_teacher` в `_week_text` (`user.py:722`).

Либо — проще и надёжнее — **склеивать всегда**, когда в наборе больше
одной группы с одинаковым слотом. Студенту это не вредит: у него в
дне одна группа, склеивать нечего.

## Что проверил и признал корректным

**`_merge_groups` склеивает по правильному ключу.** Проверил `:196`:
`(para, para_end, subject, teacher_base)`. `teacher_base` берёт первое
слово фамилии, поэтому «Иванов И.И.» и «Иванов П.П.» склеятся — но
проверил `teacher_matches:86`, там та же логика, и она уже отмечена в
плане 107 как известное ограничение.

**Дедупликация групп работает.** Проверил `:207`: `dict.fromkeys` по
уже разбитым запятыми частям — «СА - 26-2, СА - 26-2» не появится.

**`merge_groups` не влияет на студентов.** В `_fmt:392` стоит
`is_teacher`, для студента `False`. Проверил: у студента в дне одна
группа, склеивать нечего в любом случае.

**`format_teacher_results` (`:335`) тоже без склейки.** Он зовёт
`format_day` с `meta="group"`, но `merge_groups` не передаёт — поиск
преподавателя показывает поток развёрнутым. Тот же дефект, третье
место.

**`course_from_group` работает верно.** Проверил распределение по всем
129 группам: курс 1 — 38, курс 2 — 30, курс 3 — 28, курс 4 — 33.
Аномалий нет, все имена содержат год приёма в первых двух цифрах.

## Риски

- **Добавление параметра в `format_week`** меняет публичную подпись —
  проверил всех вызывающих: `user.py:722`, тесты. Правка безопасна.
- **Склейка «всегда»** может неожиданно объединить пары у студента,
  если в `college_lesson` попали строки разных групп на одну дату.
  Проверил: таких строк нет — `(date, group, para)` уникальны.
