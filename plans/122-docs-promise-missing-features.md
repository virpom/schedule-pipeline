# План 122: документация обещает то, чего нет в коде

**Приоритет:** низкий по коду, средний по доверию. Документация —
единственный способ понять проект, и в трёх местах она врёт.

**Трудоёмкость:** S (правка текста, ~5 строк).

## Расхождение 1: команда `/editlog` не существует

`docs/EDITORS.md:232`:

```
2. **История правок** — `/editlog ДП-26` (кто, что, когда).
```

Проверил все зарегистрированные команды:

```
admin, bell, broadcast, broadcast_group, broadcast_teachers, chats,
group, notify, setbell, setgroup, setnight, setpoll, setrate,
settings, setvuzanchor, stats, teachers
```

**`/editlog` среди них нет.** Функциональность при этом полная — она
просто в другом месте: кнопка «📜 Журнал правок» в редакторе
(`editor.py:75`, callback `ed:log`), обработчик `cb_log` (`:798`).

Староста дойдёт до журнала через «✏️ Редактор» → «📜 Журнал правок».
Команда `/editlog` не сработает: попадёт в `any_text` и покажет меню.

**Правка:** заменить строку на описание кнопки.

## Расхождение 2: уведомление админу о правках не реализовано

`docs/EDITORS.md:236`:

```
5. **Уведомление админу** о каждой правке старосты (можно отключить).
```

Проверил `notify_group_about_edit` (`notify_edits.py:22`) — он шлёт
**только подписчикам группы**:

```python
subscribers = await repo.users.get_subscribed_by_group(group)
targets = [u.id for u in subscribers if u.id != author_id]
```

Админ (`config.tg_bot.admin_ids`) не упоминается ни в этой функции, ни
в местах вызова (`editor.py:478`, `:735`). Никакой настройки «отключить»
тоже нет.

**Правка:** либо убрать пункт 5, либо реализовать. Если реализовать —
это уже не правка документации, а новая функция.

## Расхождение 3: уведомления в чаты группы не уходят

`docs/EDITORS.md:240`:

```
Только подписчикам **этой группы** + её чатам (не всем 215):
```

Проверил: `notify_edits.py` **не обращается к `repo.chats` вообще**.
Единственное упоминание `chats` вне админки — в `poller.py:169`, где
чаты получают плановую рассылку расписания:

```python
chats = await repo.chats.get_all()
...
for chat in chats:
    ...
    items.append((chat.id, prefix + text, photo))
```

То есть чат группы получит «🆕 Новое расписание», но **не** получит
«🔄 Замена на завтра» после правки старосты.

**Правка:** либо убрать «+ её чатам», либо добавить. Таблица `chats`
сейчас пуста (0 строк), так что поведение никого не задевает — но
описание неверно.

## Расхождение 4: устаревшее число пользователей

`docs/EDITORS.md:240` — «не всем 215».
`docs/EDITORS.md:365` — «215 юзеров / 567 пар сохранены».

Проверил на проде: **244 пользователя**, 233 подписаны. Цифра 215
устарела примерно на 30 человек.

**Правка:** заменить на актуальную или убрать число, чтобы не устаревало
снова. Лучше второе.

## Что проверил и признал корректным

**`/start` в тексте уведомления — верная подсказка.** Проверил
`start` (`user.py:397`): при наличии группы сразу показывает
сегодняшний день и меню. «Проверь расписание командой /start» —
честно.

**Остальные команды из документации существуют.** Сверил списки:
`/admin`, `/bell`, `/broadcast`, `/broadcast_group`,
`/broadcast_teachers`, `/chats`, `/group`, `/notify`, `/setbell`,
`/setgroup`, `/setnight`, `/setpoll`, `/setrate`, `/settings`,
`/setvuzanchor`, `/stats`, `/teachers` — все зарегистрированы.

**`/revoke` и `/upload` — не команды бота.** `/revoke` в
`docs/DEPLOYMENT.md:185` — это команда BotFather, `/upload` в
`docs/PARSING.md` — часть URL сайта. Ложные срабатывания моего поиска,
не расхождения.

**`/obuchayushchimsya`** — часть URL сайта ЭИОС
(`docs/SOURCE-EIOS.md:4`), не команда.

**Редактор полон.** Проверил `editor_main_kb` (`editor.py:69`): четыре
раздела — «Правки на дату», «Базовое расписание», «Журнал правок»,
«Как видят студенты». Всё, что обещает `docs/EDITORS.md`, кроме
перечисленного выше.

## Риски

- **Документация не проверяется тестами.** Это единственная причина,
  почему расхождения накопились. Если заводить проверку, самый дешёвый
  вариант — тест, который парсит `docs/*.md` на `/[a-z_]+` и сверяет
  со списком зарегистрированных команд. Но это уже отдельная задача.
- **Убирать пункты 2 и 5 из `EDITORS.md` может быть неверно.** Возможно,
  это описание задуманного, а не реализованного. Тогда правильнее
  перенести их в `docs/ROADMAP.md` как планы.
